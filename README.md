# 🏦 Geek Bank – Bank Account Management System

A console-based Bank Account Management System developed using Python. Geek Bank simulates basic banking operations, allowing users to create accounts, securely access their accounts using a PIN, and perform common financial transactions.

##  About the Project

Geek Bank was developed as a practical Python programming project to demonstrate the application of programming concepts in building a simple banking system.

The project focuses on account management, user authentication, transaction processing and input validation.

##  Features

- **Account Creation:** Create new bank accounts with automatically generated account numbers.
- **PIN Authentication:** Access accounts using a four-digit PIN.
- **Multiple Accounts:** Support for creating and managing multiple accounts.
- **Account Details:** View account information and current balance.
- **Deposit:** Add money to an account.
- **Withdrawal:** Withdraw money with balance validation.
- **Fund Transfer:** Transfer money between accounts.
- **Transaction History:** View recorded account transactions.
- **Change PIN:** Update account PIN.
- **Input Validation:** Handle invalid inputs and prevent insufficient-balance withdrawals and self-transfers.
- **Account Logout:** Securely exit an active account session.

##  Technologies Used

- Python 3
- Python dictionaries
- Functions
- Conditional statements
- Loops
- Exception handling
- Basic data validation

##  How It Works

1. Launch the program.
2. Create a new account or log in using an existing account number and PIN.
3. Select an available banking operation.
4. Complete transactions and view account information.
5. Log out or exit the application.

##  Current Limitations

- Account information is stored in memory using a Python dictionary.
- Account records are not permanently saved.
- Data is cleared when the program exits.
- This is an educational project and is not intended for real banking or financial transactions.
